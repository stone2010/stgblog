# 开源论坛项目：复盘与说明

> **当前状态：已烂尾**

## 一、原因说明

作者最初想做的是一个类似“自动表白墙”的校园论坛，希望借助匿名性提升自由度，从而规避学校老师对传统表白墙的审查。

但在实践中发现：

1. 想让普通同学在日常生活中自然、习惯性地访问一个网站，还是太困难了。
2. 项目初期用户很少，站内也没有什么有意思的内容，很难形成吸引力。
3. 曾尝试做成 WebView App，但效果也不好。

最终，项目烂尾。

## 二、作者感言

> 对于这种技术含量很低的项目，其实做出来项目不难，但是运营起来的逻辑很难跑起来。

## 三、核心结论

- **做出来不难**：技术实现不是主要障碍。
- **跑起来很难**：用户习惯、内容吸引力和运营逻辑才是关键。
